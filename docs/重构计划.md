## 1. 目标结构

```
index.html
js/
  state.js        S 状态、视图变换 i2s/s2i、render、状态栏
  recognize.js    框选识别 traceLines、内部识别
  unordered.js    无序识别（模板匹配 + 两个下拉框）
  ble.js          蓝牙接口层（适配器）
  export.js       CSV / PDF 手稿
  ui.js           工具栏、列表、模式切换、按钮绑定
  app.js          启动流程（只做初始化与装配）
style.css
sw.js            缓存列表要含 js/*.js
```

加载顺序：state → recognize → unordered → ble → export → ui → app。

## 2. BLE 接口抽象（为将来 Capacitor 做准备）

```js
window.BLE = {
  impl: 'web-bluetooth' | 'capacitor-ble',
  init(hooks),      // hooks: { onStatus, onBle, onMeasure, onPacket }
  connect(),        // 扫描/连接/订阅
  disconnect(),
}
```

- 网页版实现：`js/ble-web.js`（现在代码搬过去）；
- 将来 App 版：新增 `js/ble-native.js`（@capacitor-community/bluetooth-le），
  上层 UI 与业务代码不用改。

## 3. 实施顺序（每步都自测）

1. 先建 `js/state.js`：把 `S`、`i2s/s2i`、`render` 暴露为 `window.W`；
2. 迁移 `unordered.js`（纯逻辑，风险低）；
3. 迁移 `ble.js`（接口层 + hooks）；
4. 迁移 `recognize.js`、`export.js`、`ui.js`；
5. 瘦身 `app.js`；
6. 更新 `index.html` 脚本顺序、`sw.js` 缓存列表、单文件离线版打包脚本；
7. 冒烟测试：
   - `window.__ready === true`
   - 列表出现“暂无数据”
   - 点「无序识别」面板出现、再切回
   - 蓝牙连接按钮可点（无设备时给出提示）

## 4. 回滚方式
