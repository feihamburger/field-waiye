# 平板版 模块索引 / 记忆本

> 用途：改任何模块前先读本文件对应小节，**不要整文件通读**。
> 规则：每次改动完成后，必须更新对应小节（尤其“坑”和“当前状态”），否则下次又踩同样的坑。

## 0. 通用规则（每次改都必须遵守）

1. 改前先读本文件对应模块小节 + 目标文件相关函数；
2. 改完必须跑：
   - `node --check` 全部改过的 JS（便携 Node：`C:\Users\18000\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe`）
   - 无头浏览器打开 `http://127.0.0.1:8080/index.html?v=NNN`，确认无 `Uncaught`、列表渲染正常；
   - 涉及按钮时，点一遍或跑按钮自检（待加 `?selfcheck=1`）。
3. 脚本版本：`index.html` 里所有 `?v=NNN` 同时 +1；改 `style.css` 必须带 `style.css?v=NNN`；
4. 不要产生重复 `id`、重复函数名；改 JS 前先 `Select-String` 确认目标字符串唯一；
5. 迁移/重构原则：**新旧入口并存，新功能验证通过后再切换**，不允许“半迁移”；
6. 出问题回滚：`11-平板网页版_备份v48_20261116/`。

## 1. 文件结构

```
index.html        页面骨架（顶部 header、editBar、fcBar、jgBar、sketchBar、moreRow、unorderedPanel）
js/state.js       S 状态、视图变换、render、resizeCanvas、fitView、setStatus/setBle
js/recognize.js   附图识别：traceLinesJS、interiorRecognize
js/unordered-matcher.js  无序识别纯数学（模板、最小二乘、最少边/全部边）
js/unordered.js   无序识别 UI + 模式切换(setApp/updateModeBars) + 转手绘
js/ble-proto.js   蓝牙 20 字节协议解析
js/ble.js         蓝牙连接（window.BLE：init/connect/disconnect）
js/export.js      CSV / PDF 手稿
js/ui.js          列表渲染、itemOf、墙厚(cm)/修正计算
js/jg.js          竣工图像素识别（灰填充/黄线/黑框/柱子）
js/jg-vector.js   竣工图矢量识别（pdf.js getOperatorList）
js/interactions.js 撤销、打开图纸、autoTrace、指针事件、全部按钮绑定
app.js            启动装配（~80 行）：各模块 init、autotest/uitest 钩子、__ready
```

## 2. 模块明细

### state.js
- 导出：`window.WS = { S, $, setStatus, setBle, resizeCanvas, fitView, rotPoint, i2s, s2i, zoomAt, render, drawLabel }`
- `S` 关键字段：`img, segments, notes, columns, selected, mode, view, undo, crop, anchor, bleDevice, blePackets, app('plan'|'jg'|'sketch'|'unordered'), lengths, uoCands, uoCandIdx, autoAcc, addFrom`
- `render()`：无底图时 `hasImg=false`，跳过底图绘制但**继续画线段/注记/柱子**
- 坑：`hasImg` 必须声明在 render 内，不能插到 fitView（曾因此报 `hasImg is not defined` 全屏失效）

### recognize.js
- 导出：`window.REC = { init, traceLinesJS, interiorRecognize, interiorToSegments }`
- 依赖 hooks：`getState,setStatus,pushUndo,render,refreshList,i2s,s2i,itemOf`
- 附图流程：`traceLinesJS(useCrop)` → 合并/吸附/闭合；`interiorRecognize` 用电脑版算法

### unordered-matcher.js
- 导出：`window.UOM = { uoMatch, uoMatchMinimal?, ..., UO_TEMPLATES, UO_MINIMAL, UO5 }`
- `uoMatch(lengths, tolMm, mode)`：`mode='minimal'` 只最少边（2/4/6），`'full'` 只全部边（4/6/8），`'both'` 默认
- 规则：边不可超过最大实测值；几何有效；按参数去重；**不截断候选**（显示全部）
- 坑：5 边 U/T 模板参数必须是真实墙边；T 用含偏心参数

### unordered.js
- 导出：`window.UOR = { init, renderUnordered, uoMatch, setApp, drawUoPreview }`（内部还有 renderUoCands/updateModeBars/ensureA4/uoToSketch）
- 模式切换：`setApp(mode)` 设 `S.app`，调用 `updateModeBars()` 显示/隐藏 `editBar/fcBar/jgBar/sketchBar`
- 三个工具条互斥：plan→editBar+fcBar；jg→editBar+jgBar；sketch→editBar+sketchBar；unordered→只显示 unorderedPanel
- 转手绘：`ensureA4()` 建 A4 白纸 → `setApp('sketch')` → 同步下拉框值 `appModeSel='sketch'` → 生成线段
- 坑：改下拉框后必须同步 `S.app` 与 `sel.value`，否则“切不回去”；`updateModeBars` 用到的 id 必须真实存在

### jg.js / jg-vector.js
- `window.JG.recognize(useCrop)`：像素识别（灰填充/黄线/黑粗线/柱子）
- `window.JGV.recognizeVector(page, vp, crop)`：矢量识别（颜色精确匹配 灰0.5/洋红1,0,1/深蓝0,0,0.7；near-fill 过滤；柱子 4~15 单位）
- 入口在 interactions 的 `btnJgTrace`（矢量优先，失败回退像素）；`btnJgAdaptive` 走 JG 像素
- 坑：pdf.js 操作符要处理 `setFillGray/setFillCMYKColor` 等，否则颜色误判

### ble.js / ble-proto.js
- `window.BLE.init({setStatus,setBle,onMeasure,state})`；`connect/disconnect`；`blePackets` 调试记录
- 设备在 `+` 模式下不发累加值；平板端用 `autoAcc`（累加:关/开）自行累加
- 坑：断开后要清 `S.bleDevice`；单按钮「连接/断开」文案由 `setBle` 更新

### ui.js
- `window.UI = { init, itemOf, thicknessM, nPlus, corrected, refreshList }`
- 墙厚单位 **cm**，`thicknessM = v/100`；CSV 表头「墙厚(cm)」
- 坑：`refreshList` 里同步属性下拉框；不要引用不存在的 `$('thick')` 之前先确认 DOM

### export.js
- `window.EXP = { init, exportCsv, exportPdf }`
- 入口在「更多」里：`btnCsv`、`btnPdf`；PDF 手稿支持 `++/+-/--` 标记

### interactions.js
- 绑定：指针事件（裁剪/平移/缩放/绘图）、全部按钮、打开图纸、autoTrace、autotest/uitest 钩子
- 模式按钮绑定选择器：`document.querySelectorAll('[data-mode]')`（**不能写 `#toolbar`**，已拆分）
- 坑：新按钮若在别的模块创建，绑定要写在本文件或对应模块，且 `id` 必须与 HTML 一致

### app.js
- 仅装配：`WS`、`INT.init`、`UOR.init`、`UI.init`、`REC.init`、`BLE.init`、`EXP.init`、resize、`window.__ready=true`
- 测试钩子：`?autotest=1`（附图识别阶段统计）、`?uotest=1`（无序场景）、`?uitest=1`（模式切换检查）、`?jgtest/?jgvtest`
